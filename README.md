# sherpa-py-ldap

## Pre-requisites
- Python > 3.x
- [sherpa-py-utils](https://github.com/Identicum/sherpa-py-utils)
- apk add gcc linux-headers musl-dev openldap-dev
- python3 -m pip install python-ldap

## Deploy
```sh
python3 -m pip install --upgrade git+https://github.com/Identicum/sherpa-py-ldap.git@main
```
